# CipherLab

CipherLab is a browser-based cryptography laboratory that demonstrates five classical symmetric ciphers through an interactive web interface.

## 🔐 Implemented Ciphers

- Playfair Cipher
- Hill Cipher
- Vigenère Cipher
- One-Time Pad
- Rail Fence Cipher

## ✨ Features

- Encryption and decryption
- Interactive input and output
- Step-by-step visualization for selected algorithms
- Hill Cipher with key matrix support
- Playfair cipher using a 5×5 key matrix
- Vigenère cipher using keyword-based encryption
- One-Time Pad implementation
- Rail Fence cipher with zig-zag pattern visualization
- Runs directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project was developed as part of a Cryptography course to understand and implement classical encryption techniques and visualize how they work.
